# GClifts

A students-only ride-share for Georgia College & State University, built for the AWS for Social Good codeathon.

- **Try it:** open [`index.html`](index.html) in a browser. It runs on its own with sample data and no backend.
- **Product spec, AWS architecture and demo script:** [`MVP.md`](MVP.md)
- **AWS setup:** run `bash setup-aws.sh <profile-name>` from this folder.
